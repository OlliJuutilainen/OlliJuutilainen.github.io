Käyttöönotto

KEICK•WALK itsenäiseen käyttöön oman Cloudflare-tilin luonnin avulla. Tehdään kerran, aikaa kuluu noin 30 min. Ohjeet KEICK•WALK arkikäyttöön ovat omalla sivullaan: käyttöopas.

Uudella Macilla on lyhyempi tapa: pikakäyttöönotto (noin kymmenen minuuttia, yksi Terminal-komento, ei API-avainta eikä Cloudflaren asetussivuja).

Tällä ohjeella keikkasi ovat sinun Cloudflare-tililläsi ja äänitiedostot sinun Google Drivessasi tai Dropboxissasi. Ollin sivu on vain näyttämö: se soittaa keikan, jonka linkki osoittaa sinun tiliisi. Olli ei näe keikkojasi, ellet anna hänelle linkkiä, eikä hänen tilinsä osallistu mihinkään.

Käyttöönoton jälkeen uusi keikka on viiden minuutin homma: äänitiedosto Driveen tai Dropboxiin, settilista lomakkeeseen, yksi komento Terminaliin.

Lopussa on liite lisäominaisuudesta, jossa keikka kootaan kansiosta ja jokainen kappale on oma tiedostonsa. Tavallinen keikka ei tarvitse siitä mitään.

Mitä tarvitset

  • Macin. Komennot käyttävät vain Terminalia ja ohjelmia, jotka ovat valmiina jokaisessa Macissa (curl, security). Mitään ei asenneta.
  • Ilmaisen Cloudflare-tilin. Ilmaistason rajat (100 000 hakua ja 1 000 tallennusta päivässä) ovat moninkertaiset tähän tarpeeseen.
  • Google Driven tai Dropboxin äänitiedostoille. Molemmat on kokeiltu toimiviksi. Dropbox-tiedosto soi suoraan Dropboxista, Drive-tiedosto workerin kautta, joten Dropbox voi periaatteessa toimia hieman jouheammin. Tarkista oma valintasi testikeikassa (kohta 9).

Miten osat liittyvät toisiinsa

  • KEICK•WALK on osoitteessa ollijuutilainen.github.io/soitin/#tunnus@soitin.jotain. Kaikki #-merkin jälkeinen jää selaimeen eikä kulje GitHubin palvelimille.
  • Keikkaloihdin tarkistaa settilistan ja tekee valmiin tallennuskomennon. Se ei lähetä mitään verkkoon.
  • Worker on pieni ohjelma Cloudflaressa. Se lukee keikan KV-tietokannasta ja antaa sen KEICK•WALK-sivulle. Drive-tiedoston se myös välittää KEICK•WALK-sivulle, koska Google ei anna soittaa Drive-tiedostoa suoraan toiselta sivustolta. Dropbox-tiedosto soi suoraan.

Kuka tahansa, jolla on keikan linkki, näkee otsikon ja settilistan ja voi kuunnella äänitteen. Linkki on siis avain. Tunnus on arvottu, joten sitä ei voi arvata.

Salaiset avaimet. Cloudflaren API-avain (kohta 6) ja kansiokeikan avaimet (liite) ovat salaisia. Älä liitä niitä sähköpostiin, viestiin, muistiinpanoon tai tekoälykeskusteluun. Tämä sivu ei kysy niitä. Tilin tunnus, KV-tunnus, workerin osoite ja Dropboxin App key eivät ole salaisia.

Kirjoita tunnukset tämän sivun kenttiin sitä mukaa kuin saat ne. Sivu täyttää ne komentoihin ja linkkeihin. Ne jäävät vain tämän selaimen muistiin, jotta voit jatkaa myöhemmin; sivu ei lähetä niitä minnekään.

6API-avain

Avain antaa Terminalin komennolle luvan tallentaa keikkoja tietokantaan.

Avaa avainlomake (Create Token). Älä muuta lomakkeessa mitään. Se näyttää enimmäkseen tyhjältä, ja niin sen kuuluukin. Tarkista, että se näyttää tältä:

Jos Permissions-rivillä ei lue Workers KV Storage, valitse se itse. Jos linkki ei avaa lomaketta lainkaan: oikean yläkulman profiili → My Profile → API Tokens → Create Token → Create Custom Token → Get started, ja valitse kentät taulukon mukaisiksi.

  1. Continue to summary → Create Token.

Älä sulje Cloudflaren sivua, jolla avain näkyy. Cloudflare näyttää avaimen vain tämän kerran. Seuraavassa kohdassa se kopioidaan sivulta suoraan Macin avainnippuun, ja vasta sen jälkeen sivun saa sulkea. Avainta ei kirjoiteta talteen minnekään muualle.

Avaimella voi muuttaa kaikkia tilisi KV-tietokantoja, joten älä liitä sitä viestiin, muistiinpanoon tai tekoälykeskusteluun.

Suljin sivun ennen kuin ehdin kopioida avaimen

Avainta ei saa enää näkyviin, mutta samalle avaimelle voi tehdä uuden arvon:

  1. My Profile → API Tokens.
  2. Avaimen rivin valikko (…) → Roll. Cloudflare tekee samoilla oikeuksilla uuden arvon ja näyttää sen kerran. Vanha arvo lakkaa toimimasta.
  3. Jätä sivu auki ja jatka kohdasta 7.

Jos valikossa ei ole Roll-vaihtoehtoa, poista avain (Delete) ja tee uusi tämän kohdan ohjeella.

7Avain Macin avainnippuun

  1. Avaa Terminal (Ohjelmat → Lisäohjelmat → Pääte). Kopioi tämä komento ja liitä se Terminaliin, mutta älä vielä paina Enteriä: 
    security add-generic-password -U -a "$USER" -s soitin-cf -w "$(pbpaste)"
  2. Kopioi avain Cloudflaren sivulta.
  3. Paina Terminalissa Enter. Älä paina sitä ennen kuin avain on kopioitu: komento lukee leikepöydän vasta Enterin hetkellä. Onnistuessaan komento ei tulosta mitään.

    Terminal ei kysy mitään salasanaa, ei Macin salasanaa eikä uutta itse keksittävää salasanaa, eikä mitään tarvitse kirjoittaa. Jos Terminal silti kysyy jotain, paina ctrl+C ja tarkista, että komento on liitetty kokonaan.

  4. Tarkista, että avainnippuun tallentui avain. Komento ei näytä avainta, vain sen pituuden: 
    security find-generic-password -s soitin-cf -w | awk '{ print "pituus", length($0), "välilyöntejä", gsub(/ /,"") }'
    Pituuden pitää olla kymmeniä merkkejä (esimerkiksi pituus 53 välilyöntejä 0). Jos pituus on pieni, leikepöydällä oli jotain muuta: toista vaiheet 1–3.
  5. Tarkista, että Cloudflare hyväksyy avaimen: 
    curl -sS https://api.cloudflare.com/client/v4/user/tokens/verify -H "Authorization: Bearer $(security find-generic-password -s soitin-cf -w)"; echo
    Vastauksessa pitää olla "status":"active".
  6. Nyt voit sulkea Cloudflaren avainsivun. Tallennuskomento lukee avaimen avainnipusta itse, joten se ei näy ruudulla eikä päädy mihinkään tiedostoon.
Avainnippuun meni jotain muuta kuin avain

Esimerkiksi pituustarkistus näyttää pienen luvun, tai tarkistus vastaa Invalid format for Authorization header. Siivottavaa ei ole: toista vaiheet 1–5. -U korvaa avainnipussa olevan arvon, oli siellä mitä tahansa. Terminalin komentohistoriaan jää vain komennon teksti "$(pbpaste)", ei avain eikä se, mitä leikepöydällä oli.

Jos Cloudflaren avainsivu ehti sulkeutua, tee ensin uusi arvo (kohdan 6 lopun Suljin sivun ennen kuin ehdin kopioida avaimen).

Jos avain vaihtuu myöhemmin (esim. Roll), toista vaiheet 1–5 uudella avaimella. -U korvaa vanhan.

8Keikkaloihtimen kirjanmerkki

Tämä on Keikkaloihtimen osoite sinun tunnuksillasi:

https://ollijuutilainen.github.io/soitin/uusi.html#w={w}&a={a}&n={n}

Avaa Keikkaloihdin ja tallenna se kirjanmerkiksi (⌘D). Sivun yläreunassa pitää lukea Omat asetukset: {w}.workers.dev. Jos jokin tunnus on väärän mittainen, sivu kertoo sen punaisella.

Avaa Keikkaloihdin aina tästä kirjanmerkistä. Osoitteen loppu (#w=…&a=…&n=…) kertoo Keikkaloihtimelle sinun tunnuksesi. Jos osoitteesta puuttuu tämä loppu, yläreunassa ei lue Omat asetukset, ja sivu tekee komennon Ollin tilille. Se ei toimi sinun Macillasi.

Liite: keikka kansiosta (lisäominaisuus)

Tavallinen keikka ei tarvitse mitään tästä liitteestä. Lue se vain, jos haluat keikan, jossa jokainen kappale on oma äänitiedostonsa.

Kansiokeikassa annetaan yhden äänitiedoston ja settilistan sijaan jaettu kansio Google Drivesta tai Dropboxista. KEICK•WALK soittaa kansion äänitiedostot peräkkäin, ja kappaleiden nimet tulevat tiedostonimistä. Kansiokeikan teko ja tiedostojen nimeäminen: käyttöoppaan liite.

Worker lukee kansion palvelun omasta rajapinnasta, ja siihen tarvitaan avain. Tee vain sen palvelun käyttöönotto, jota käytät; molempia voi käyttää rinnakkain.

K1. Workerin koodi

Kansiokeikka tarvitsee 14.10.2026 tai myöhemmin päivitetyn koodin. Jos teit kohdan 2 ennen sitä, päivitä worker (Workerin päivitys). Sitten joko K2A tai K2B.

K2A. Google Drive

Drivessa ei tarvita sovellusta eikä pysyvää avainta, vain API-avain. Sillä worker saa lukea kansioita, jotka on jaettu kaikille linkin saaneille. Muuhun Driveesi se ei pääse. Drive API:n käyttö on maksutonta.

  1. Avaa console.cloud.google.com ja kirjaudu Google-tililläsi. Hyväksy ehdot, jos niitä kysytään.
  2. Yläpalkin projektivalitsin → New project → nimeksi soitin → Create. Varmista, että uusi projekti on valittuna yläpalkissa.
  3. Avaa Google Drive API → Enable.
  4. Credentials → Create credentials → API key. Avautuvassa ikkunassa:
    • API restrictions: Restrict key → Google Drive API.
    • Application restrictions: None, koska avainta käyttää worker eikä selain.
    • Kohtaa Authenticate API calls through a service account ei valita.
    Create. Kopioi avain.

    Jos ikkunassa ei ole rajauksia, luo avain ja rajaa se jälkikäteen: avaimen kohdalla kynä (Edit API key) → API restrictions → Restrict key → Google Drive API → Save.

  5. Workers & Pages → soitin → Settings → Variables and Secrets → Add. Type: Secret, Variable name: GOOGLE_API_KEY (täsmälleen näin), arvoksi API-avain. Deploy.

Avain ei avaa mitään, mikä ei jo ole jaettu kaikille linkin saaneille, mutta pidä se silti salaisena.

K2B. Dropbox

Dropbox-sovellus. Sovellus on vain avain, jolla workerisi saa lukea Dropboxiasi.

  1. Avaa dropbox.com/developers/apps ja kirjaudu omalla Dropbox-tililläsi.
  2. Create app → Scoped access → Full Dropbox → nimeksi esim. soitin- ja oma nimesi (nimen pitää olla Dropboxissa ainutlaatuinen) → Create app.
  3. Välilehti Permissions: ruksi files.metadata.read, files.content.read ja sharing.read, ja paina alhaalta Submit. Tee tämä ennen seuraavia vaiheita: avain saa vain ne oikeudet, jotka ovat päällä sen tekohetkellä.
  4. Välilehti Settings: kopioi App key tähän. App secret (Show) tarvitaan pian, mutta sitä ei kirjoiteta tälle sivulle.

Kaikki oikeudet ovat lukuoikeuksia: avaimella ei voi muuttaa eikä poistaa mitään. App secret on silti salainen.

Pysyvä avain (refresh token).

  1. https://www.dropbox.com/oauth2/authorize?client_id={dk}&response_type=code&token_access_type=offline → Continue → Allow. Sivulle tulee koodi. Kopioi se tähän:

  1. Aja Terminalissa heti: 
    curl -sS https://api.dropboxapi.com/oauth2/token -d code={dc} -d grant_type=authorization_code -u {dk}
    Terminal kysyy Enter host password for user '…': liitä App secret ja paina Enter (kirjoittaessa ei näy mitään).
  2. Vastauksessa on "refresh_token": "…". Kopioi lainausmerkkien välinen osa; se on salainen kuten App secret. Jos vastaus on invalid_grant, koodi ehti vanhentua tai sitä käytettiin jo. Avaa vaiheen 5 linkki uudelleen ja aja komento uudella koodilla.

Salaisuudet workeriin. Workers & Pages → soitin → Settings → Variables and Secrets → Add. Lisää kolme muuttujaa, joiden Type on Secret, ja paina Deploy:

Variable nameArvo
DROPBOX_APP_KEYApp key
DROPBOX_APP_SECRETApp secret
DROPBOX_REFRESH_TOKENrefresh token
