# Kolmansien osapuolten kirjastot (luin/pdf/)

Ladataan vasta, kun tekstistä tehdään PDF (Imuroi › PDF). Tiedostot ovat julkaisupakettien sellaisinaan, versio nimessä.

- `paged-0.4.3.polyfill.min.js`: Paged.js 0.4.3 (npm `pagedjs`), MIT, Copyright (c) 2018 Adam Hyde.
- `pdf-lib-1.17.1.min.js`: pdf-lib 1.17.1 (npm `pdf-lib`), MIT, Copyright (c) 2019 Andrew Dillon.
- `fontkit-1.1.1.min.js`: @pdf-lib/fontkit 1.1.1 (npm), MIT; Andrew Dillonin haara Devon Govettin fontkitistä, Copyright (c) Devon Govett.

PDF:n kirjasimet `luin/fontit/literata-pdf-*.ttf` ovat Literatan (SIL Open Font License 1.1, `luin/fontit/OFL.txt`) staattisia instansseja: npm `@fontsource-variable/literata` 5.3.0, osajoukot latin, latin-ext, vietnamese, greek, greek-ext, cyrillic ja cyrillic-ext yhdistettyinä, paino 400 tai 700, optinen koko 12.
